# Mobile applicability

## Applicability

Apply mobile guidance only to an explicitly selected mobile task (Swift/iOS,
Kotlin/Android, KMP or CMP). For all other work, follow the pinned core unchanged
and do not load the mobile workflow adapter.

For explicit mobile work, read [mobile workflows](mobile-workflows.md) in full
before selecting the route or executing a phase. Its intent-first routing,
regression, arena, target-proof and verification-skill requirements remain
mandatory. Read its proof references when that phase requires them.
