# Orca

This page maps Orca CLI 1.4.241, observed on 2026-10-28. On another CLI version, treat each row as unobserved until it is checked again. Pass `--json` to every command below and read its result.

| Row | Mechanics |
|---|---|
| Detect | `ORCA_TERMINAL_HANDLE`, `ORCA_PANE_KEY` or `ORCA_TAB_ID` is set. An Orca pane sets all three, and every process the pane starts inherits them. |
| Sessions and worktrees | A session is a pane with a handle `term_<uuid>`. To turn a `tabId:leafId` pane ID into a handle, run `orca terminal list --json`. Make each worker's checkout with `git worktree add`, never `orca worktree create`. `--worktree path:<abs>` resolves only a path that `orca worktree list` shows. The match is byte for byte after symlinks resolve, so pass the path `pwd -P` prints. On macOS, `/tmp` resolves to `/private/tmp`. Any other path, such as a fresh clone, returns `selector_not_found`. `name:` and `branch:` selectors accept a slash. |
| Start | In a worktree Orca shows, run `orca agent launch --agent <claude or codex> --worktree path:<abs> --surface terminal --model <id> --effort <level> --prompt <text>`. Elsewhere, run `orca terminal create --command "cd <abs> && claude --model <id> --effort <level>"` and send the prompt. Orca opens that pane in its active workspace, so record the pane's `ORCA_WORKTREE_ID` beside its `cd` target. Start the prompt with `/hstack:hugues-mode` for Claude Code and `$hugues-mode` for Codex (#131). Record the requested model and effort and the effective ones from the worker's init record. Unobserved: `agent launch` with `--model` and `--effort`, and any Codex pane. |
| Send | `orca terminal send --terminal <handle> --text <text> --enter --wait-submit 20`. The turn has started when `result.send.prompt.stages` contains `turn_started`. A send that times out returns the input-accepted receipt, and Orca does not resend it. Reissue it only with the `--retry-request <id>` it reports. |
| Read | `orca terminal read --terminal <handle> --cursor <n>`, where `<n>` is the previous read's `nextCursor`. `--screen` reads the rendered frame and takes no `--cursor`. |
| Wait | Stop waiting at the first of three ends, and report which one it was: DONE in the worker's status file, `orca terminal wait --terminal <handle> --for tui-idle --timeout-ms <ms>`, or that wait's timeout. Branch on `ok`, then on `error.code`. A timeout returns `ok: false`, `error.code: "timeout"` and no `result`. A satisfied wait returns `result.wait.satisfied: true`. `tui-idle` does not fire while a Claude Code permission card is up, so that wait times out. A Codex or omp card is unobserved. An idle pane is not DONE. |
| Close | After DONE and its evidence, run `orca terminal close --terminal <handle>` and log it. It returns `result.close.ptyKilled: true` and kills the pane's whole process tree, MCP servers included. Close a round's pane before the next round creates one. After `terminal_handle_stale`, run `orca terminal list --json` and use only a replacement it lists. Report a handle that is gone as a lost worker, and never call it again. Unobserved: `terminal_handle_stale` itself. |
| Load a PR head | A pane loads a head the way its agent does outside Orca. For Claude Code, start the pane with `orca terminal create --command "cd <abs> && claude --plugin-dir <worktree>/plugin"`, because `agent launch` passes no other agent flag. Then confirm from the transcript which `hugues-mode/SKILL.md` it read. Unobserved: Codex. |
| Allowed tools | Use the `orca terminal` commands `create`, `send`, `read`, `wait`, `close` and `list`, and `orca agent launch`. Use `orca worktree list`, `show` and `current` to read only. An observer only lists and reads panes it does not own. It never sends to, creates or closes one. `orca-emulator` and `orca-emulator-android` are not installed and stay unmapped. Workers run with approvals off. That is a setting in the Orca app, because the CLI has no flag for it. Nobody types an approval into a pane. |
| Skip line | Skipped in Orca: Orca Runs, Tasks, Dispatches, inboxes, `worker_done`, heartbeats and the `orchestration` skill. hStack dispatches, waits for and settles the work, and #50 has kept Orca terminal-only since 2026-10-19. |
