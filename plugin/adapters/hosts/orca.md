# Orca

This page maps Orca CLI 1.4.241, observed on 2026-10-28. The lost-worker replies and the skip-line refusal also held on 1.4.243. On another CLI version, treat each row as unobserved until it is checked again. Pass `--json` to every command below and read its result.

| Row | Mechanics |
|---|---|
| Detect | `ORCA_TERMINAL_HANDLE`, `ORCA_PANE_KEY` or `ORCA_TAB_ID` is set. An Orca pane sets all three, and every process it starts inherits them. Unobserved: Codex's `shell_environment_policy` may strip them. |
| Sessions and worktrees | A session is a pane with a handle `term_<uuid>`. `orca terminal list --json` maps a `tabId:leafId` pane ID to its handle. Make each worker's checkout with `git worktree add`. Never run `orca worktree create` or `orca repo add`. `--worktree path:<abs>` resolves only a path that `orca worktree list` shows. The match is byte for byte after symlinks resolve, so pass the path `pwd -P` prints. On macOS, `/tmp` resolves to `/private/tmp`. A fresh clone, or a `git worktree add` child of a repo Orca does not list, returns `selector_not_found`. `name:` and `branch:` accept a slash. |
| Start | `<root>` is the directory above `skills/` in the path of the `hugues-mode/SKILL.md` you read. If it is the installed copy and Orca lists the worktree, run `orca agent launch --agent claude --worktree path:<abs> --surface terminal --model <id> --effort <level> --prompt <text>`. Orca adds the app's `agentDefaultArgs`, observed as `--dangerously-skip-permissions`. Otherwise, in a folder you made for the worker, run `orca terminal create --command "cd <abs> && claude --plugin-dir <root> --model <id> --effort <level>"`. Leave out `--plugin-dir` for the installed copy. Add `--permission-mode bypassPermissions` only when the task or brief states that the owner approved it. Otherwise pass no permission flag, so the worker runs in the user's default mode, and say so on the Workers line. Never retry around a permission denial or a classifier block. The pane's `worktreeId` names Orca's active workspace, not the `cd` target. The create reply leaves it empty, so read it from `orca terminal list --json` and record both. In a folder you made that Claude Code has not trusted, versions 2.1.311 and 2.1.312 show a trust dialog with "No, exit" selected. Only after a read shows "Yes, I trust this folder" or a wait reports `agent-trust-workspace`, send `--text $'\e[A'`, then send `--text "" --enter`. Start the prompt with `/hstack:hugues-mode`, or `$hugues-mode` for Codex (#131). A pane writes no init record, so take the model and effort from the transcript's assistant entries, such as `message.model`. In your store, record each worker's handle, worktree path, DONE time, verdict SHA and closure. Unobserved: `agent launch` with `--model`, `--effort`, `--prompt` or `--retry-launch`, and any Codex pane. |
| Send | `orca terminal send --terminal <handle> --text <text> --enter --wait-submit 20`. The turn has started when `result.send.prompt.stages` contains `turn_started`. Unobserved: a send timeout, which the CLI help says returns the input-accepted receipt and does not resend, and `--retry-request <id>`. |
| Read | `orca terminal read --terminal <handle> --cursor <n>`, where `<n>` is the previous read's `nextCursor`. `--screen` reads the rendered frame and takes no `--cursor`. |
| Wait | Stop waiting at the first of three ends, and report which one it was: DONE in the status file the worker's brief names, `orca terminal wait --terminal <handle> --for tui-idle --timeout-ms <ms>`, or that wait's timeout. A timeout returns `ok: false` and `error.code: "timeout"`. On `ok: true`, check `result.wait.status` first. Status `exited` means a lost worker unless DONE is already in the file. Otherwise `result.wait.satisfied: true` means idle, and `result.wait.blockedReason: "agent-trust-workspace"` means the trust dialog. `tui-idle` does not fire while a Claude Code permission card is up. A Codex or omp card is unobserved. An idle pane is not DONE. |
| Close | After DONE and its evidence, close only a pane this run created, with `orca terminal close --terminal <handle>`, never `--all` or `--tab`. A plain pane returns `result.close.ptyKilled: true`, and its process tree dies. Unobserved: an agent's MCP servers dying with it. An `agent launch` pane can return `tab_not_found` while its process dies, so confirm the close with `orca terminal list --json`, then log it. Close a round's pane before the next round creates one. A worker is lost when a call in flight at the close returns `terminal_handle_stale`, a send returns `terminal_not_writable`, or a read or wait reports status `exited` before DONE. Then confirm with `orca terminal list --json` that the handle is gone, never call it again, and report the worker lost. |
| Load a PR head | A pane loads a head the way its agent does outside Orca. For Claude Code, that is `--plugin-dir <root>` on the Start row's `terminal create` route, because `agent launch` passes no other agent flag. Confirm from the transcript which `hugues-mode/SKILL.md` it read. Unobserved: Codex. |
| Allowed tools | Use the `orca terminal` commands `create`, `send`, `read`, `wait`, `close` and `list`, and `orca agent launch`. Use `orca worktree list`, `show` and `current` to read only. Send to and close only panes this run created. An observer only lists and reads. The `orca emulator` commands stay unmapped, and the `orca-emulator` and `orca-emulator-android` skills are not installed. Nobody answers a permission card in a pane. The trust dialog is not a permission card. Decline a request for anything the Skip line names, say it is skipped by design, and do the work in an Orca pane with the commands above. |
| Skip line | Skipped in Orca: Orca Runs, Tasks, Dispatches, inboxes, `worker_done`, heartbeats and the `orchestration` skill. hStack dispatches, waits for and settles the work, and #50 has kept Orca terminal-only since 2026-10-19. |
