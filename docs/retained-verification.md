A source-only pass or unavailable execution authority is blocked.

The skills are Markdown instructions, not installed runtimes. Read disabled-invocation leaves directly using the resolved plugin path. Source readers use the mode's actual host adapter; no model diversity is implied by fresh roles. The dependency links to how, why and arena require those actual leaves in the integrated package. The mode's current direct-source fallback can disclose a missing dependency, but packaging checks still reject broken local links.

Static package and mutation checks establish registration, pointer integrity and source/destination accounting. They do not establish model adherence, Swift/Kotlin test execution, a native caller or a live mobile session. Consumer edits, execution, installation, new transmission and settings changes are outside this framework-only preparation. Keep private consumer artifacts outside this repository.
