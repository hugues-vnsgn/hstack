The adaptation uses the existing [host adapter](../plugin/skills/hugues-mode/references/host-notes.md)
for Claude Code Agent and Codex native subagents. Research roles inherit the
parent model by default. Markdown reads replace attempts to invoke leaves whose
frontmatter disables model invocation. Actual schemas determine tool arguments;
a declared read-only assignment preserves available MCP read access without
assuming Cursor Task, Ask, model slugs or an unsupported `readonly` field.

Source playbooks keep upstream search patterns and caveats. Their index makes
service names and query names conditional examples, with actual schema and access
checks before use. Local git/history and `gh`/PR access are verified separately.
The warehouse reference treats upstream column conventions as examples to check,
rather than a fact about every consumer schema. The synthesizer template replaces
an unresolvable example URL with an instruction to cite a verified URL.

Consumer research reads source and existing artifacts. Read-only source queries, including schema inspection and SQL retrieval, proceed
within the current research request and authorized access. Tests, app launches,
builds, devices, service writes/setup or new private-data transmission outside
that source scope require explicit current human authority. Tools that launch
new AI analyses follow the same boundary. Actual authority or capability gaps
leave a prepared query and a recorded limit. Source review does not execute the app.
Research sends no messages, edits no consumer files and performs no service setup.

Validation uses the existing package and upstream checkers, strict Claude
metadata validation, Python unittest discovery, shell syntax and whitespace
checks. The retained research regressions mutate package files and receipts to
check discovery, local links and provenance rejection. These are static package
checks; they do not prove native host invocation, delegated research quality,
MCP access or mobile runtime behavior. No new consumer run or observed host proof
is claimed here. The coordinator owns final routing/document integration and
independent acceptance review.
